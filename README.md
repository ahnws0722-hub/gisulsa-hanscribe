# 건설안전기술사 하루 한 문제 필사

건설안전기술사 서술형 대비를 위한 **하루 한 문제 필사** 웹 앱입니다. 참고 답안을 보며 옮겨 쓰고, 기록을 기기 안에 저장합니다.

## 사용법

1. 사이트를 엽니다.  
   **https://ahnws0722-hub.github.io/gisulsa-hanscribe/**
2. 오늘의 문제를 열거나 목록에서 회차를 고릅니다.
3. 답안을 보면서 필사란에 옮겨 씁니다. 쓴 내용은 브라우저에 자동 저장됩니다.
4. **기록 백업(내려받기)** / **기록 불러오기**로 JSON 백업·복원이 가능합니다.
5. **+ 내 문제·답안 추가**로 실제 기출·본인 답안을 넣을 수 있습니다.

## 아이폰 홈 화면에 추가

1. Safari로 위 주소를 엽니다.
2. 공유 → **홈 화면에 추가**.
3. 홈 화면에서 바로 필사 연습을 이어갈 수 있습니다.

## 주간 내용 추가

작업 복사본: `/workspace/gisulsa-hanscribe/index.html`  
문제·답안 데이터와 UI가 같은 파일에 있습니다. 수정 후 `main`에 푸시하면 Pages가 반영됩니다.

## 고지

수록 답안은 AI가 작성한 **참고답안**이며, 한국산업인력공단 공식 모범답안이 아닙니다. 법령 수치는 국가법령정보센터 최신 조문으로 확인하세요.
